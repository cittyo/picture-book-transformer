Picture Book Transformer Skill 🎨
一个专为 AI Agent 和创作者打造的通用技能插件（Skill）。支持将任意输入角色、宠物或日常图片转换为具有细腻颗粒噪点、冷压水彩纸底纹与打字机文字排版的治愈系日式绘本插画。

适用平台
各类兼容 Agent Skill 规范的智能体平台

Claude Code / Cursor / Codex 等开发型代理

安装与使用
只需将本仓库克隆至你的 Agent 项目技能目录，或直接导入 .agent/skills/picture-book-transformer/SKILL.md。

git clone https://github.com/cittyo/picture-book-transformer.git
在对话中直接发送图片并附带指令：

“将这张图片转成绘本风”
